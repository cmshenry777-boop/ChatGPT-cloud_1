# 빅투 Big Two — 모바일 세로 화면용

[onlinesologames.com/bigtwo](https://www.onlinesologames.com/bigtwo)를 폰에서 하기 불편해서 새로 만든 버전이에요.
봇 3명(또는 2명)과 오프라인으로 플레이하고, 규칙은 수업 자료 *Card Gaming – Day 7 Intro to Big Two*를 따라요.

## 원래 사이트와 다른 점

| | 원래 사이트 | 이 버전 |
|---|---|---|
| 카드 크기 | 게임판 전체를 축소해서 보여 줌 | 손패를 두 줄로 겹쳐 폰 폭에 꽉 차게 표시 (390px 폭 기준 카드 약 100px) |
| 선명도 | 캔버스 이미지 | HTML/CSS + 벡터 무늬라 고해상도 화면에서도 또렷함 |
| 조작 | 탭 | 탭, 손가락으로 쓸어서 여러 장 선택, 힌트 버튼, 숫자순/무늬순 정렬 |
| 광고 | 있음 | 없음 |
| 이어하기 | 새로고침하면 사라짐 | 자동 저장돼서 다시 열면 이어서 진행 |

## 규칙 (PDF 기준)

- 카드 순서 3 < … < K < A < 2, 무늬 ♦ < ♣ < ♥ < ♠. 3♦가 제일 약하고 2♠가 제일 셈.
- 3♦를 가진 사람이 3♦를 포함한 패로 시작하고 시계 방향으로 진행.
- 싱글·페어·트리플·5장 패. 같은 장수로 더 센 패만 낼 수 있고, 언제든 패스 가능.
- 5장 패: 스트레이트 < 플러시 < 풀하우스 < 포카드(+1) < 스트레이트 플러시 < 로열 플러시. 투페어 없음.
- 플러시·스트레이트 플러시는 무늬 먼저, 같은 무늬면 높은 카드로 비교.
- 벌점: 남은 카드 1~8장은 장당 1점, 9장 이상은 장당 2점, 한 장도 못 냈으면 장당 3점(13장 → 39점).
- 5라운드 후(또는 누군가 50점 도달 시) 점수가 가장 낮은 사람이 우승. 설정에서 바꿀 수 있어요.
- 3명일 때는 17장씩, 남은 1장은 3♦를 가진 사람이(그 카드가 3♦라면 3♣를 가진 사람이) 가져감.

PDF에 없어서 정한 부분: 스트레이트는 A-2-3-4-5(가장 낮음)부터 10-J-Q-K-A(가장 높음)까지이고,
J-Q-K-A-2처럼 넘어가는 건 안 돼요. 매 라운드 3♦를 가진 사람이 시작해요.

## 실행

정적 파일이라 아무 웹 서버에나 올리면 돼요.

```sh
cd big-two
python3 -m http.server 8000   # http://localhost:8000
npm test                      # 규칙 테스트 + 봇끼리 80판 자동 대전
```

크롬·삼성 인터넷에서 메뉴 → **홈 화면에 추가**를 하면 앱처럼 전체 화면으로 열리고, 오프라인에서도 돼요(HTTPS 필요).

## 구조

- `js/rules.js` — 카드, 족보 판정, 비교, 벌점 (순수 함수)
- `js/game.js` — 딜링, 턴, 트릭, 라운드/게임 종료
- `js/ai.js` — 봇 전략
- `js/app.js` — 화면 그리기와 입력 처리
- `sw.js`, `manifest.webmanifest` — 오프라인 지원과 홈 화면 설치
